**结论：物料编码 999-999999 在本知识网络中没有数据** —— 它不在物料主数据里，也没有库存行、采购订单行和销售订单行。这是「查无此物料」，不能读作「库存为 0、订单为 0」。

## 已查范围与命中

| 查询对象 | 匹配字段 | 精确 == | 子串 like |

- **库存**：没有任何仓库的库存行，因此没有可用库存/预留库存数字可报。若日后有数据，该对象的可用字段是 `inventory_qty`（库存数量）、`available_inventory_qty`（可用库存数量，定义为 库存数量 − 预留库存数量）、`reserved_inventory_qty`（预留库存数量）、`warehouse`（仓库名称）、`stock_status`（库存状态）。

## 已发布的关联能力也一致

- **替代料状态**（物料编码 999-999999）→ 执行失败：`CannotCompute「物料未配置替代组：999-999999」`

## 范围说明

本网现有物料编码形如 `101-000002`、`165-000005`，与 `999-999999` 同构，所以可排除「编码格式不符」这一解释；但不能排除编码本身有误，或该物料数据未接入本知识网络。以上 0 行只证明在所查的这几个对象类范围内无该编码数据，**不代表其他系统或库外场景下的库存与订单为零**。

如果你确认编码无误，我可以换个方向：用「物料反查产品」看该物料是否挂在某个 BOM 分支上，或按名称/规格模糊搜一遍物料主数据。
