# 业务溯源平台一致性：独立验收基线

日期：2026-11-02。范围：DSH 当前会话内的业务溯源详情。

## 基线与证据等级

布局与交互基线是本地平台 `bkn-studio` 的 `release/0.2.0` 提交 `90d3b92a909a3b98ad3e74b78b08ecf4fbdc3535`。选定组件、service、types、证据组件与许可共 7 个 Git blob 已由主智能体核对；这不代表当前部署页面已核对相同字节。

独立断言的中文文案来自该版本原始 `locales/zh-CN.ts`：**时间链**、证据链、本轮业务执行过程、调用状态筛选、复制 Markdown、下载 Markdown、交给 BKN Agent 分析。不能只检查插件字典键集合，或从待测字典自动生成期待文本。

受控数据位于 `packages/openbkn-business-context/tests/fixtures/provenance-parity/conversation.json`，明确标记 `controlled-synthetic` / `notLiveEvidence`。它有 73 轮，按平台新到旧排序，入口选中第 7 轮（不在首 50 轮）、同 Operation ID 两次 attempt、普通 operations、受管函数、原文精度、缺失输出、平台 invalid 原因及历史结果。它不是真实业务调用、不是真实 Host 或模型验收。

## 差异白名单

1. 删除“返回业务溯源列表”：入口上下文已经是当前 DSH 会话。
2. DSH 外层窗口尺寸、关闭/焦点、宿主主题/语言、剪贴板/下载底层 API、Host 认证运输可以适配，保持操作含义及平台内容完整。
3. 可信入口目标不存在或首屏未披露时，不能继承平台旧快照回退首项的行为；必须保持精确目标与明确边界。
4. 相同 Operation ID 的多 attempt 必须保留各次事实与独立选择，不可被 React key 或选择状态合并。

其他差异不自动纳入白名单。平台本身缺失/partial/invalid 状态也不算插件“修正”。

当前实现另有两项运输/权限差异，留待实机验收决策，不能据此宣称完全一致：HTTP 失败仅返回固定分类及状态，不显示任意响应体原因；detail 不可读时 KN 预检会阻止旧版页面的 Trace Markdown 回退。业务记录中的 invalid 原因和已解析 SSE 错误仍保留。来源与影响见[后端合同复核](./CONTRACT-REVIEW.zh.md)。

同一 Interaction 的列表元数据更新保留当前详情及生成/分析；真正换轮和显式刷新才重置详情生命周期。两项受控回归修前失败、修后通过。最终完整结果见[验证回执](./VALIDATION.json)，不能用旧中间计数代替。

## 验收矩阵

| 边界 | 独立受控断言 | 真实 Host / 平台 / 人工要求 |
| --- | --- | --- |
| 入口精确定位 | 73 轮中点选第 7 轮；详情不是第 73 轮或首项；questionPairs 不代替轮次 | 同一真实 DSH 回答与平台 Interaction 对照 |
| 轮次导航 | 新到旧顺序、搜索、分页/收起、选中；首屏外/搜索不可见/partial/truncated 不误回退 | 已有真实多轮会话，比较选中与刷新行为 |
| 原文 | 本轮输入/输出全文与平台字段一致；原文精度与缺失提示保留 | 同账号同记录对比，不替换为 DSH 最终回答 |
| 页面结构 | 原文在时间链/证据链之上；普通调用列表与详情左右布局；无全局返回入口 | 相近窗口尺寸截图对比、窗口缩放与焦点 |
| 普通 operations | 状态计数/筛选/空筛选、对象/条件/资源/结果/接口、原始 input/output/error | 真实普通查询记录逐字段对照 |
| 多次尝试 | 相同 opId 的 attempt 1/2 独立选中，失败与成功 payload 不混合 | 真实重试样本；父子与 attempt 对照 |
| managedTimeRail | capability evidence_contract 选择平台受管函数路径；父子、输入/输出/错误保留 | 真实受管函数样本 |
| 证据视图 | 阅读/图谱、业务/本体/技术、节点/关系详情及图操作；invalid 状态/原因原样展示 | 同一非空证据图交互与视觉对比 |
| 共享输入 | 共享来源的有效关联保留；相同值不新增平台未声明的跨分支边 | 与平台同记录对照；不重新推断业务来源 |
| Markdown | 使用平台 Markdown 内容复制/下载；不拼接插件结论；只在显式操作发起 | macOS 原生剪贴板/文件保存；Windows 单独执行 |
| 刷新 | 重读已存在详情/解释；不自动 generate/analyze；选择按基线保持 | 真实记录刷新及 token/TLS/权限边界 |
| 主动动作 | 生成/更新解释与 Agent 分析只由显式点击触发；等待/流式/错误/历史 | 仅在另行允许的测试环境执行真实 POST |
| 运输预算 | chunk index/end/encoding、UTF-8 总预算、取消、中断、错误脱敏 | 真实 Typert 长包与慢请求，不以 mock 代填 |
| 范围保护 | 已有非溯源源码 SHA-256 逐文件不变；共享文件逐 hunk 复核 | 登录、MCP、业务工具未扩大修改范围 |

## 发布前仍须区分的未完成证据

自动化渲染/行为检查通过只能证明受控输入下的组件与适配器行为。它不能代替真实 DSH Host / Typert 集成、同记录的平台页面对照、macOS 复制下载、Windows 原生执行、真实权限/TLS/长记录、真实生成/分析以及用户人工验收。未执行的项目保留“未执行”，不能由测试数量代填。
